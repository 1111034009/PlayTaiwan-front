
# 🎮 PlayTaiwan

> 🗺️ 一場帶你用 App 解謎遊玩，並輸出專屬紀錄短影音的旅遊體驗。

PLAYTAIWAN 是一款以臺灣旅遊探索為主題的 Flutter 應用程式，結合旅遊地點探索、故事任務、地圖導覽、收藏與回憶，以及店家影音宣傳和後台管理功能。

使用者可以透過故事與任務探索地方，店家則能管理店家資料、題庫、優惠券及宣傳影音。

## ✨ 功能介紹

### 👤 一般使用者

- 🔐 **帳號功能**：登入、註冊、帳號資料與密碼相關操作。
- 🗺️ **旅遊探索**：依地點與偏好探索旅遊內容，生成故事劇本旅遊探索。
- 🏆 **收藏與回顧**：查看收藏、徽章、過往故事紀錄及相關媒體。
- 🎬 **明信片與影音**：瀏覽故事明信片，查看或下載 Vlog 影片。
- 🤝 **配對功能**：提供配對加入及配對大廳相關頁面。

### 🏪 店家功能

- 📝 **店家註冊與資料管理**：填寫店家資料、管理帳號與營業資訊。
- 🤖 **AI 宣傳影音**：輸入影音生成資料、查看生成進度、檢查及瀏覽生成結果。
- 📁 **檔案管理**：查看最近生成的檔案及歷史檔案。
- 🧩 **題庫管理**：新增、編輯與管理玩家任務題目。
- 🎟️ **優惠券管理**：管理優惠券相關資料及畫面。

### 🛠️ 管理後台

- 👥 **帳號管理**：查詢、建立、修改及刪除使用者資料。
- 📖 **故事管理**：查詢與管理故事資料。
- 🏅 **徽章管理**：管理徽章相關內容。
- 📊 **訪客分析**：提供訪客分析儀表板及策略對話介面。

## 🧰 技術架構

- 📱 **開發框架**：Flutter / Dart
- 🎨 **使用者介面**：Material Design
- 🌐 **語系設定**：以繁體中文（`zh_TW`）為預設語系。
- 🔗 **API 串接**：使用 HTTP 與後端 API 溝通。
- ⚙️ **環境設定**：使用 `flutter_dotenv` 讀取 `.env`。
- 🔑 **登入狀態管理**：集中於 `AppSession` 管理 Token 與店家相關資料，並由 `AuthGuard` 協助處理登入保護。
- 🎵 **音訊管理**：使用 `audioplayers` 與 `BgmService` 管理音訊及背景音樂。

## 💻 開發環境與啟動

請先確認電腦已安裝 Flutter SDK、Dart SDK，以及對應平台所需的開發工具，例如 Android Studio、Android SDK。若要建置 iOS，則需使用 macOS 與 Xcode。

### 📥 1. 取得專案

取得完整專案原始碼，並進入 Flutter 專案根目錄。

### 📦 2. 安裝 Flutter 套件

在專案根目錄執行：

```bash
flutter pub get
```

### ▶️ 3. 啟動專案

套件安裝完成後，執行：

```bash
flutter run
```

即可啟動 Flutter 專案。

### 📱 4. 查看可用裝置

如果電腦上有多個裝置，可以先查看目前可用的裝置：

```bash
flutter devices
```

再指定裝置執行：

```bash
flutter run -d <device_id>
```

例如，使用 Chrome 執行：

```bash
flutter run -d chrome
```

### 🔄 5. 熱重載與重新啟動

在 `flutter run` 執行期間，可於終端機輸入以下指令：

- **🔃 Hot Reload**：輸入 `r`，重新載入程式碼變更。

```text
r
```

- **♻️ Hot Restart**：輸入 `R`，重新啟動 Flutter 應用程式。

```text
R
```
